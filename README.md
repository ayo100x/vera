# VERA

**Commerce intelligence for discovering, comparing, and deciding what to buy.**

VERA is a product-discovery experience built around a simple problem: you see something you want online, but finding the exact product, better alternatives, or knowing whether it is actually worth buying can be difficult.

VERA is designed to turn that moment of discovery into a clearer purchasing decision.

## The Idea

**See something → Show VERA → Understand it → Find matches → Compare → Decide**

Users can start with an image, product inspiration, or a natural-language request. VERA then presents relevant products and alternatives based on the user's intent.

## Current Experience

* Image-based product discovery
* Natural-language product searches
* Product and outfit understanding
* Visual match results
* Exact and similar product options
* Cheaper alternatives
* Premium alternatives
* Complete-the-look recommendations
* Product comparison
* Responsive, modern interface
* Product detail pages

## Running Locally

Clone the repository:

```bash
git clone https://github.com/ayo100x/vera.git
```

Move into the web application:

```bash
cd vera/apps/web
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL provided by Vite.
