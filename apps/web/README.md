# VERA Web

The frontend application for VERA.

## Stack

* React
* JavaScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* React Router

## Development

From the `apps/web` directory:

```bash
npm install
npm run dev
```

The application will start using the Vite development server.

## Structure

```text
web/
├── public/
└── src/
    ├── app/
    └── pages/
```

The root repository README contains the overall project description and direction.
